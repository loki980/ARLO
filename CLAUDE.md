# ARLO

Arc Raiders Loot Overlay. Python 3.11+, Tk overlay, Tesseract OCR, SQLite item
database synced from public APIs. Linux (X11 or Wayland) and Windows.

## Commands

- `uv sync --all-extras` then `uv run pytest -q` for the suite.
- `uv run ruff check src tests` and `uv run ruff format --check src tests`.
  Master has a known baseline of lint errors and unformatted files outside the
  new code. New code must add none.
- `uv run arc-helper` runs the overlay, `uv run arc-calibrate` the calibration
  tool, `uv run python update_db.py --merge` the database updater.

## Conventions

- Commit messages are imperative, one line of summary, in the style of
  `git log`.
- `items.db` is tracked and regenerated by the updater. Do not commit a
  rebuilt `items.db` as part of a code change.
- `.env` and `.env.example` are blocked for agents by the permission settings.
  Changes there are made by Jeffrey.
