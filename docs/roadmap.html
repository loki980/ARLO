Five things we learned today

1

ARLO has been flying blind on recycling since April. The MetaForge database key it used was revoked on 2026-04-02. Every weekly update since then quietly fell back to the wiki. Nobody noticed because the fallback mostly agrees.

2

Quest needs never made it into the database. The quest parser reads a field the API does not have, so it maps zero items. The "After Rain Comes" line you see today came from wiki prose, not from the quest feed.

3

Your instinct about recycling was right, and it has a name. In a raid the action is called Salvage and it uses its own table, usually a smaller one. Power Bank gives 2 Battery and 2 Wires at home but only 2 Battery in the field. Both tables are public, and they agree across MetaForge, ARC Tracker, and the wiki for almost every item.

4

ARC Tracker is a vision pipeline, and we can borrow the shape without the code. A detector finds every slot, an embedding model names the icon, a guided stash scroll builds a ledger, and it only scans when the stash is open and still. Their trick we get for free: when the tooltip names an item, remember what its icon looked like. ARLO already reads the tooltip.

5

Per-cell badges are the one risky piece on Wayland. Dozens of little windows will not do. We need one transparent click-through surface over the game, which the current toolkit cannot draw. A short spike decides the approach before any badge code exists.

Technical notes, for when you want them

How ARLO works today. A scanner thread OCRs a fixed region for the word INVENTORY every half second, then OCRs a cursor-relative crop every 0.3 s to read the hovered name. The crop is masked to the tooltip's cream background, which is why the tooltip rectangle is almost free. One click-through Tk popup draws the result in a corner. The database has six columns, and quest, project, and workshop needs live only as wiki prose in one text field. On Wayland the capture backend keeps the latest full frame in memory, so a full-screen grab costs one crop. 51 tests pass, none cover the overlay or the updater yet.

Data sources, chosen. ARC Tracker's public JSON API for items (price, stack, rarity, recycle and salvage maps, stable icon URLs), quests (all nine Frozen Trail quests with structured needs), and projects (Expedition 1 to 5 with dates). MetaForge for workshop levels, the only source with Outpost 1 to 4. The wiki stays as fallback. Twelve recycle rows disagree between the APIs and the wiki and want an in-game check.

What ARC Tracker 2.3.2 does. Windows Graphics Capture at 15 Hz, scanning at 4 Hz, gated by a frame classifier and a motion check. A YOLO11 slot detector, a DINOv2 embedding gallery of 1,416 crops over 915 items, a separate weapon tier classifier, glyph reading for stack counts, rarity from the colored disc. Badges in a transparent Electron window, a hover card placed beside the game's tooltip, a stash ledger stitched from a guided scroll, and screen readers for workshop, project, quest, and blueprint pages.
